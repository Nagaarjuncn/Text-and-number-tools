# Text and Number Tools

A lightweight Python command-line utility that analyzes text input and checks whether a given number is prime.

## Features
- **Word Count (`wc`):** Splits the input sentence by whitespace and counts the total number of words.
- **Longest Word (`lw`):** Identifies and returns the longest word in the sentence.
- **Reverse Sentence (`rs`):** Reverses the characters of the input sentence using string slicing.
- **Prime Checker (`pc`):** Determines if a given integer is a prime number by testing divisibility up to its square root.
